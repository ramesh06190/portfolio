How I work on accessibility

  1. Start with native HTML

    Real buttons, labels, landmarks and headings first. ARIA only fills gaps that HTML cannot.

  2. Test automatically

    axe DevTools and Lighthouse during development, and axe in the build pipeline so regressions fail the build.

  3. Test by hand

    Keyboard only walkthroughs, screen reader checks, 200% zoom, 320px reflow and contrast checks on every new screen.

  4. Track by criterion

    Log each issue against its WCAG 2.1 success criterion and severity so fixes are prioritized and verifiable.
